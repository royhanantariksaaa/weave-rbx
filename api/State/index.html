State

Common readable state surface. Mutable state types additionally expose Set and Update.

Functions​

</>
State:Get() → any

Returns the current value and tracks the read when inside a computation.

</>

</>
State:Update(updater: (any) → any) → ()

</>
State:Peek() → any
