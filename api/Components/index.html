Components

Built-in component constructors. Each receives the owning Scope first and returns ordinary Roblox Instances or rendering nodes.

Functions​

Button​

</>
Components.Button(
scope: Scope,
props: {[any]: any}
) → TextButton

Creates a TextButton with owned hovering and pressed state. Optional props include HoverState, PressState, and ordinary TextButton props.

Flex​

</>
Components.Flex(
scope: Scope,
props: {[any]: any}
) → Frame

Creates a Frame with UIListLayout. Component props include Direction, Wrap, Justify, Align, Gap, and Children.

TextInput​

</>
Components.TextInput(
scope: Scope,
props: {[any]: any}
) → TextBox

Creates a TextBox with optional TextState, OnChange, and OnSubmit behavior.

Tooltip​

</>
Components.Tooltip(
scope: Scope,
props: {[any]: any}
) → any

Creates hover content through a Portal. Target and PortalTarget Instances are required; Content or Children supplies the tooltip body.

VirtualList​

</>
Components.VirtualList(
scope: Scope,
props: {[any]: any}
) → ScrollingFrame

Creates a fixed-row-height ScrollingFrame that renders only the visible range. Required props: Items and RenderItem; ItemHeight defaults to 50.
