Weave

Root module for scope creation, mounting, unscoped reactive state, rendering symbols, context, styles, lazy loading, components, and debug controls.

Properties​

children​

This item is read only and cannot be modified. Read Only
</>
Weave.children: any

Symbol key for an explicit children array. PascalCase alias: Children.

ref​

This item is read only and cannot be modified. Read Only
</>
Weave.ref: any

Symbol key that writes a constructed Instance into a mutable State or Ref. PascalCase alias: Ref.

Components​

This item is read only and cannot be modified. Read Only
</>
Weave.Components: Components

Built-in Button, Flex, TextInput, Tooltip, and VirtualList table.

Debug​

</>
Weave.Debug: boolean | string?

Set true to collect counters, "overlay" to mount the client profiler, or nil/false to disable debug tracking.

Functions​

onEvent​

</>
Weave.onEvent(eventName: string) → any

Returns a collision-proof symbol key for an Instance event. PascalCase alias: OnEvent.

onChange​

</>
Weave.onChange(propertyName: string) → any

Returns a symbol key for GetPropertyChangedSignal. The callback receives no property value. PascalCase alias: OnChange.

bind​

</>
Weave.bind(propertyName: string) → any

Returns a two-way property binding symbol. The supplied state must be mutable to accept Instance-to-state writes. PascalCase alias: Bind.

scope​

</>
Weave.scope(parentScope: Scope?) → Scope

Creates a manual Scope. parentScope supplies inherited context and component lookup; destroy a manually created child explicitly.

Creates a root Scope, runs a builder, parents its result, and returns the unmount function. Supplying props or a name wraps output in a ScreenGui.

</>

batch​

</>
Weave.batch(callback: () → ...any) → ...any

Defers propagation until the outermost synchronous batch closes and preserves callback return values. PascalCase alias: Batch.

peek​

</>
Weave.peek(state: any) → any

Reads a state without dependency tracking or forcing a pending Computed. PascalCase alias: Peek.

destroy​

</>
Weave.destroy(state: any) → ()

Releases an unscoped state or animation object. Repeated destruction is ignored. PascalCase alias: Destroy.

</>
